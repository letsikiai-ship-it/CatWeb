# CatWeb

# Overview
  This project will demonstrate how Ai can be used to retrieve data from a database and preset it to the user.
  It will then be integrated to webiste that promotes a friendly user interaction .

# Features
    The Catweb application will retrieve varies facts in the designated database and present the relevant answer to the user's question

#  Technologies used
  The tools that were used to create this project are the following:
    Python3
    Ollama AI model
    Flask for website framework
    html 
    css
# Project Structure
   CatWeb/
       |--Website/
               |--templates
               |--static
       |--main.py
       |--businessLogic.py
       |--database_for_cats.py

 # Installation
   To be able to run this program, you will need vs-code latest version, install python3, install Ollama ai model, have a database and Flask.
   this application is not intended for public use but if you are interested you can try to run it in your device at your own risk.
   Do check the system this project was built on in the requirements folder, this will help you gauge the system requirements.

 # Usage
   To run this application you will need cat knowledge, it is straight forward. Just sign up and you will be redirected to the dash board where you can ask
   the Ai bot some questions about cats. do be patient as it takes time to respond
